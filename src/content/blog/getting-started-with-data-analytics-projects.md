## Start with a question

Every good analytics project begins with a clear question, such as "Which products drive most of our sales?" A focused question tells you which data you need and when you are done.

## A simple workflow

1. **Collect** the data from a CSV file, database or public dataset.
2. **Clean** it: fix data types, handle missing values and remove duplicates.
3. **Explore** it with summary statistics and quick charts.
4. **Communicate** the findings in a dashboard or short report.

## Tools you can use

- Python with Pandas for cleaning and analysis
- SQL for querying databases
- Power BI, Tableau or Streamlit for dashboards

## Keep it small

A finished small project teaches more than an abandoned big one. Publish your code and write down what you learned.
